# Built-in wallpaper assets

The 10 WebP thumbnails in this directory are derived from Unsplash images, resized to
400 px wide and re-encoded at quality 75 for the built-in wallpaper grid. The matching
`full-01.webp` … `full-10.webp` files are 1920 px wide, quality 70, and are used as the
actual wallpaper background (no runtime Unsplash request; the remote URL is only an
`onError` fallback).

- Source: <https://unsplash.com>

- Downloaded/re-encoded: 2026-10-28
